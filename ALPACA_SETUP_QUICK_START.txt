================================================================================
ALPACA CREDENTIALS SETUP - QUICK START
================================================================================

WHAT: Phase 8 (trade execution) needs Alpaca paper trading API credentials
WHY: Without credentials, algo can generate signals but cannot execute trades
WHERE: https://alpaca.markets (your account)

================================================================================
GET YOUR CREDENTIALS (2 MINUTES)
================================================================================

1. Go to: https://alpaca.markets/account/
2. Click: Settings → API Keys (or Account Settings → API)
3. Copy BOTH:
   - API Key ID (looks like: PK_PAPER_xxxxxxxxxxxxx)
   - Secret Key (long random string)

NOTE: Make sure you're using PAPER trading, not LIVE trading credentials!

================================================================================
SETUP LOCAL DEV (CHOOSE ONE METHOD)
================================================================================

METHOD 1: ONE-TIME SETUP (Current Session Only)
-------------------------------------------------
Run this in your terminal:

export APCA_API_KEY_ID="PK_PAPER_xxxxxxxxxxxxx"
export APCA_API_SECRET_KEY="your_secret_key_here"
source scripts/setup_local_alpaca_credentials.sh

Then verify:
python check_system_health.py

This only lasts until you close the terminal.


METHOD 2: PERSISTENT SETUP (Recommended)
-----------------------------------------
Add to your shell profile (~/.bashrc or ~/.zshrc):

export APCA_API_KEY_ID="PK_PAPER_xxxxxxxxxxxxx"
export APCA_API_SECRET_KEY="your_secret_key_here"

Then reload:
source ~/.bashrc
# OR
source ~/.zshrc

Now every new terminal session has your credentials.


METHOD 3: WINDOWS POWERSHELL
-----------------------------
$env:APCA_API_KEY_ID = "PK_PAPER_xxxxxxxxxxxxx"
$env:APCA_API_SECRET_KEY = "your_secret_key_here"

# Then run orchestrator in same PowerShell session
python scripts/run_local_orchestrator.py

================================================================================
VERIFY SETUP WORKED
================================================================================

After setting credentials, run:

python check_system_health.py

Look for:
[OK] Alpaca Credentials
    APCA_API_KEY_ID: PK_PAPER_...
    APCA_API_SECRET_KEY: (set)

If you see [WARN] or [FAIL], credentials not set properly.


OR test directly:

python -c "
import os
key = os.getenv('APCA_API_KEY_ID')
secret = os.getenv('APCA_API_SECRET_KEY')
print(f'API Key: {key}')
print(f'Secret Key: {\"SET\" if secret else \"NOT SET\"}')"

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Alpaca credentials not found" error
A: Make sure you ran the export/set commands BEFORE running orchestrator
   Try: echo $APCA_API_KEY_ID (should show your key)

Q: "Invalid API Key" error
A: Double-check you copied the FULL key (both parts)
   Make sure you're using PAPER trading key, not LIVE

Q: "Connection refused" error
A: Alpaca API might be down. Check: https://status.alpaca.markets/

Q: Want to use LIVE trading instead?
A: Get LIVE credentials from Alpaca dashboard
   Replace PK_PAPER_ with actual LIVE key
   WARNING: Real money at risk - not recommended for testing
