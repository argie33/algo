## ISSUE #4: SILENT ERROR LOGGING (Exception swallowing)

### database_health_monitor.py:70
```python
except (KeyError, ValueError, AttributeError) as e:
    logger.debug(f"Could not check connection pool health: {e}")
    # SILENT FAILURE - operators won't see this
```

**Problem:** Uses DEBUG level instead of WARNING. Operators won't see pool health failures.

**Better:** `logger.warning(...)` or `raise RuntimeError(...)`

### database_health_monitor.py:155
```python
except (psycopg2.DatabaseError, psycopg2.OperationalError) as e:
    logger.debug(f"  Health check failed: {e}")
    # SILENT FAILURE - operators won't see database issues
```

**Problem:** Database diagnostic failures logged at DEBUG level, hidden from operators.
