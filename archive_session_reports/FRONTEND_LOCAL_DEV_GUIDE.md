# Frontend Local Development Guide

## Quick Start (Recommended)

### One Command Setup
```bash
npm run start
```

This runs the **complete setup**:
1. ✅ `npm run setup-dev` — Configures frontend for local development (localhost API)
2. ✅ Starts Vite dev server on **localhost:5174** (if 5173 is in use)
3. ✅ Opens to development environment

**First run:** ~30s  
**Subsequent runs:** Instant

---

## Manual Setup (if needed)

### Terminal 1: Prepare Frontend
```bash
cd webapp/frontend
npm run setup-dev  # Creates public/config.js with LOCAL API settings
npm run dev        # Starts Vite dev server on localhost:5174
```

### Terminal 2: Start API Server (Required!)
```bash
python lambda/api/dev_server.py
# Output: Starting API dev server on http://localhost:3001
```

### Terminal 3: Open in Browser
```
http://localhost:5174
```

Press **F12** to check console — should show no CORS errors ✅

## Environment Modes

### Mode 1: Local Development (✅ CURRENT)
- **Frontend runs on:** `localhost:5174`
- **API calls go to:** `localhost:3001` (via Vite proxy)
- **Setup file:** Run `npm run setup-dev`
- **Config:** `public/config.js` with `API_URL: ""`
- **Use case:** Development & testing locally

**Advantages:**
- No AWS credentials needed
- Fast iteration
- Works offline
- Full stack control

### Mode 2: AWS Production
- **Frontend deployed to:** CloudFront CDN
- **API calls go to:** AWS Lambda Gateway
- **Setup file:** Run `npm run build-prod`
- **Config:** `public/config.js` with `API_URL: "https://..."`
- **Use case:** Live application

**Setup:**
```bash
npm run build-prod  # Builds and generates production config.js
npm run deploy:full # Validates and builds
```

## What config.js Does

The `public/config.js` file controls where API calls go:

**Local Dev Version** (after `npm run setup-dev`):
```javascript
window.__CONFIG__ = {
  "API_URL": "",           // ← Empty = Use Vite proxy (localhost:3001)
  "ENVIRONMENT": "development",
  // ... other fields
}
```

**Production Version** (after `npm run setup-prod`):
```javascript
window.__CONFIG__ = {
  "API_URL": "https://2iqq1qhltj.execute-api.us-east-1.amazonaws.com",
  "ENVIRONMENT": "production",
  // ... other fields
}
```

## Troubleshooting

### CORS Errors in Console?
**Problem:** `Access to XMLHttpRequest... blocked by CORS policy`

**Solution:**
```bash
npm run setup-dev  # Re-generate config.js for local dev
npm run dev        # Restart Vite server
```

### 404 Errors in Console?
**Problem:** `Failed to load resource: status 404`

**Solution:** Make sure dev API server is running:
```bash
python lambda/api/dev_server.py
```

### Page shows "Data not available"?
**Problem:** All dashboard panels show no data

**Causes:**
1. Dev API server not running → Start: `python lambda/api/dev_server.py`
2. Frontend still pointed to AWS → Run: `npm run setup-dev`
3. Vite proxy misconfigured → Check vite.config.js

### Vite Dev Server Won't Start?
**Problem:** Port 5173 already in use

**Solution:** Auto-handled! Vite uses next available port (usually 5174)  
Check console output for actual port

## How It Works (Under the Hood)

### 1. Frontend Startup Flow
1. Browser loads `index.html`
2. Script tag loads `public/config.js` (sets `window.__CONFIG__`)
3. React renders (`main.jsx`)
4. API client reads `window.__CONFIG__.API_URL`
5. API calls use `baseURL` from config

### 2. Vite Proxy in Development
```
Frontend (localhost:5174)
  ↓ calls /api/market/top-movers
  ↓ Vite proxy intercepts
  ↓ routes to http://localhost:3001
  ↓ Dev server responds with data
  ↓ Frontend displays data
```

### 3. AWS in Production
```
Frontend (CloudFront CDN)
  ↓ calls https://api-gateway-url/api/market/top-movers
  ↓ Direct HTTPS request to AWS
  ↓ Lambda processes request
  ↓ Returns data (CORS headers included)
  ↓ Frontend displays data
```
