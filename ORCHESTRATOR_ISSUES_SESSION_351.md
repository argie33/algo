4. Progress: Only 40/5478 symbols (1%) in 2+ minutes
5. At this rate, 5478 symbols would take 200+ minutes (3+ hours)

**Why This Happens**:
- yfinance is making HTTP requests to Yahoo Finance API
- API is slow, timing out, or rate-limiting
- Each batch of 20 symbols takes 0.8-1.0 seconds
- Total load time for 5478 symbols: 5+ hours
- This explains why earlier "hung" loaders took 10-15 hours

**Evidence**:
```

Line 174: [yfinance] Batch calling yf.download for 20 symbols with 180s timeout
Line 182-195: Progress stuck at 40/5478 (1%) - 3 batches in 2 minutes
```

**Key Issue**: The loader tries to fetch 7 days of historical data for 5478 symbols from yfinance. This is:
- 5478 × 7 = 38,346 days of price data
- But with batching (20 symbols/batch) = ~274 batches
- Each batch: 0.8-1.0 seconds
- **Total time: 220-270 seconds (3.5-4.5 minutes minimum)**

But we observed 15+ hour completion times, which suggests the loader was also retrying failed requests or waiting for API responses.
